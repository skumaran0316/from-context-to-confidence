# From context to confidence

Portable static website, version 30 (18 November 2026).

## Hosting
Unzip this archive. Upload the contents of the site/ folder to the web root of a static website host. index.html must be at the root. No build command, package installation, database, API key, or server code is needed. Keep the CSS and JavaScript files alongside index.html.

To preview locally, open site/index.html in a modern browser. Optionally serve site/ with any local static web server.

The simulation is scripted and uses fictional records. It does not call a live AI model, database, dbt, or Fivetran service. Diagrams are embedded SVG. Google Fonts is loaded over the Internet; system fallback fonts work if unavailable. Research links open external websites.

This copy does not include ChatGPT Sites authentication or sharing controls. Choose access settings on the destination host before publishing. The original site is unchanged. If importing into a personal ChatGPT account, create a new Site from these files; availability and sharing options depend on that account.
