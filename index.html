How can you build this today?

You can build custom evaluations with dbt SQL or Python models where your data platform supports them. Store test questions and results in tables, calculate scores, and use dbt tests to flag results that miss your thresholds. dbt can run these steps alongside your other models in scheduled jobs.

Your data platform must support the code and Python libraries you choose, with permission to securely call any AI service it needs. If the agent runs elsewhere, bring its answers back into dbt to evaluate them. Your team builds this custom workflow.

dbt Evals is in development. dbt has published a proposal for bringing agent evaluation into its workflow; this is not a general-availability announcement.

Data tests and agent evals answer different questions. “Are these records valid?” is not the same as “Did the agent use the right information and answer correctly?”

PRESENTER NOTES

One story. Five scenes.

  1. See the mistake. Send the question. The agent calculates bookings correctly but calls it revenue. A real agent might instead ask for clarification; this is one possible failure.
  2. Prepare context. Walk through ingestion, approved modeling and source-linked evidence. Explain that a sync is not a dbt rebuild and neither is an agent eval.
  3. Compare answers. Send the same question with the prepared context. The changed result is grounded in a different, correct business definition.
  4. Run an eval. Read the team’s expectations before revealing the example eval results. Explain that the numbers are compared locally from fixed fixtures, while the explanation review is scripted. Distinguish the recorded agent output from the independent reference and evaluator’s comparison.
  5. Catch a regression. Run without account-level evidence. The number still passes, but the explanation is incomplete. Restore evidence, ask again, then explicitly rerun the eval.

For a deeper discussion, use the optional trace, data journey and shared-definition diagram. These are illustrations, not measured benchmarks or a product UI.
